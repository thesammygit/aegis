# AEGIS Roadmap

This roadmap summarizes the recommended development order. The detailed guidance for each step lives in [`docs/development/README.md`](./development/README.md).

The repository currently stops at Phase 0 by design.

## Phase 00

- agree on workflow, tooling, and ADR process
- confirm what "done" means for each future phase

## Phase 01

- demo data served through real contracts
- dashboard and detail skeleton from seeded events

## Phase 02

- CelesTrak ingest for a small subset
- timestamped snapshots and fallback demo data

## Phase 03

- practical screening pipeline
- candidate events with TCA and miss distance

## Phase 04

- explainable ranking
- operator-facing event dashboard

## Phase 05

- event detail page
- encounter-plane-style geometry view

## Phase 06

- maneuver sandbox
- downstream short-horizon rescan

## Phase 07

- persistence and reproducibility
- Docker Compose end-to-end
- docs, caveats, and verification hardening

## Later Phases

- optional risk atlas
- larger catalog coverage
- richer uncertainty handling
